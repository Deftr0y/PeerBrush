SETUP

Run PeerBrush

Download a native build for your platform. Rust is only required to develop from source.

Full getting-started guide
  1. 01

    Download and extract

    Windows: run peerbrush.exe. Linux and macOS: run the extracted peerbrush executable. Linux may need chmod +x peerbrush.

  2. 02

    Open an image

    Use File → Open, or drop an image into the workspace. New and opened documents have separate project tabs.

  3. 03

    Save your project

    Save as PSD to keep layers and masks. Export PNG for a merged image at the document’s channel depth.

AI CONNECTION

Connect an agent

Agents inspect the actual canvas and edit through the same document engine. AI changes appear in blue.

Codex · Claude Desktop · Cursor · Gemini CLI

MCP setup and tool reference
  1. 01

    Click Connect AI in PeerBrush

    The app registers with detected clients and preserves their existing settings.

  2. 02

    Reload your AI client

    Approve the connection if prompted. A green MCP indicator in PeerBrush confirms a connected client.

Choose your model in the AI client. PeerBrush is free; separate AI providers may charge for their services.

Supported formats

Compatibility details
FormatCurrent supportBehavior
PSD v1 · RGB · 8 / 16 bitEditable, supported structuresRaster layers, groups, supported blends and raster masks. Saves include a current merged composite.
PNG 8 / 16 bitImport & exportExport retains the document’s native channel depth.
JPEG / BMPImage importOpen or import as raster content.
Unsupported PSD structuresProtected previewRead-only merged preview. An explicit flattened copy retains the original precision.
PSB / other color modesNot supportedFull Photoshop compatibility and full color management are pending.
