# Transforms that retain original pixels

Whole-layer rotation and scaling retain the original native raster and an accumulated affine placement. Every preview and finished gesture samples that original, so shrinking then enlarging or rotating repeatedly does not repeatedly filter the previous result. Exact inverse placement restores native words, including hidden RGB, without an 8-bit editing copy. Move changes document placement without resampling. Hidden folder descendants use the same operation and pivot.

Each painted mask step retains its own original and placement. Effects, mask operations, hierarchy and blend settings remain editable. Changing only a mask preserves the color original; painting color preserves unaffected mask originals. Pixel editing establishes a new baseline from the current appearance for the changed raster. This includes painting, clone/heal, fills, direct pixel adjustments, image replacement, and selected-pixel transformations. Undo restores the preceding pixels and originals together. Image size explicitly resamples the document and establishes new raster baselines, as does an explicit channel-depth conversion; crop and canvas size retain the existing samples and placement.

UI, MCP and CLI use the same `transform` and `move` commands, reservations, locks and revision guards. With an active selection, use `selection_only:false` to transform the whole layer. Selected-pixel operations continue to edit that region as raster artwork. Live previews contain actual shared-engine pixels, and finishing a gesture produces one undo step.

Unreleased snapping (PB-123): `move` and `transform` accept optional `snap:true`. The shared engine resolves values before preview, reservations and history: move deltas round to the nearest 8 document pixels, angles to 15°, and positive scale factors to 0.1. Invalid flags, numeric types and out-of-range raw values reject atomically. `snap:false` or an omitted flag preserves free transformation. The UI holds both scale axes equal while Shift is down and returns to the chosen axis when Shift is released. Snapping applies to the same layer, folder, mask or selected-pixel target as a free transform, at the original native depth. Pan/zoom does not change the move grid. Small scales snap to at least 0.1; existing transform size/work budgets still apply.

Unreleased selection corrections (PB-110): native copy gives an active pixel selection precedence over the last layer-row click. Selected copies retain exact coverage, holes, feathering, document coordinates and native channels. A selected folder transforms only selected pixels in its raster descendants, including hidden children, using one original selection and pivot. Folder masks and hierarchy stay in place for Color selection transforms; text/vector and adjustment children require explicit rasterization. Multiple selected layers/folders share the same selection baseline in both live previews and committed edits. Selection transforms honor reservations on the selection geometry as well as affected layers. Whole-layer copy remains available after deselecting; selected-pixel cut is still unsupported and never deletes complete layers.

Unreleased transform actions (PB-124): W/E/R show compact Mirror H, Mirror V and clockwise/counterclockwise 90° actions. Each applies once around the selected pixels or selected roots' common center, with one undo step. Selecting both a folder and its descendant does not transform the descendant twice. Color actions include hidden descendants and attached masks; choosing Mask transforms only its selected paint step, leaving Color, other steps and children unchanged. Whole-mask transformations keep their original samples, including off-frame samples, for later inverse edits. Selected-mask transformations use the shared coverage renderer. Editable text/vector Color definitions remain editable; their existing selected-pixel/mask restrictions still apply. Folder mask movement through the Move command remains unsupported.

Shared `transform` commands accept optional boolean `mirror_x` and `mirror_y`. Positive `scale_x`/`scale_y` magnitudes remain 0.05–20; reflection flags apply before rotation around the document-space pivot. Preview, CLI and MCP use the same interpretation and reservations, including the selection's destination. PSD saves retain current standard raster/mask channels and merged pixels; this adds no Photoshop-style import support.

Windows copy retains a message-only clipboard owner on the worker thread and services its messages while idle. Image writes publish a native-depth PNG and a standard display-depth DIBV5 bitmap with explicit alpha. Encoding finishes before opening and clearing the clipboard. Failed writes do not replace the internal buffer or delete source layers. This follows the [Windows clipboard ownership requirement](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setclipboarddata).

Shrinking or moving artwork changes its content bounds, while the document canvas remains available for raster editing. Painting, masks, smudge, clone/heal, fills, shapes and gradients can reach outside the transformed content. When needed, the engine expands sparse layer storage to include the canvas and keeps existing off-canvas samples. Pixels are copied at their original channel depth, including hidden RGB; mask steps and local liquify controls move with the storage frame. Unchanged transform originals retain their original samples and receive only a coordinate translation. Active selections and explicit masks still apply. Undo restores the preceding storage frame and originals together. Layers whose storage does not cover the canvas use the ordinary shared-engine stroke preview until expansion, avoiding a fixed incremental clip.

Observation exposes `transform_source` for each retained color raster and painted mask step: original width, height, bit depth, source bytes and the affine matrix `[a,b,c,d,tx,ty]` mapping original local coordinates to the current local frame. Sample data stays in the document, not in observation responses.

PSD saves contain current standard layer raster/mask channels and a current merged composite. Supplementary PeerBrush source format 9 preserves originals for later edits and inverse transforms after reopening. Photoshop receives the current raster appearance; this does not create Photoshop Smart Objects. Earlier PeerBrush readers protect these newer documents as read-only.

Original tiles use copy-on-write snapshots and are counted alongside current raster projections in the 512 MiB document budget. Transform dimensions retain the 8192-edge/32-megapixel limits, with a 128-million-sample work bound per layer command. Invalid, reserved, locked or over-budget requests roll back atomically. Nested originals are refused; derived preview caches remain outside history and saved source definitions.
