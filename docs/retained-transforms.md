# Transforms that retain original pixels

Whole-layer rotation, scaling and skew retain the original native raster and an accumulated affine placement. Every preview and finished gesture samples that original, so shrinking then enlarging or rotating repeatedly does not repeatedly filter the previous result. Exact inverse placement restores native words, including hidden RGB, without an 8-bit editing copy. Move changes document placement without resampling. Hidden folder descendants use the same operation and pivot.

Each painted mask step retains its own original and placement. Effects, mask operations, hierarchy and blend settings remain editable. Changing only a mask preserves the color original; painting color preserves unaffected mask originals. Pixel editing establishes a new baseline from the current appearance for the changed raster. This includes painting, clone/heal, fills, direct pixel adjustments, image replacement, and selected-pixel transformations. Undo restores the preceding pixels and originals together. Image size explicitly resamples the document and establishes new raster baselines, as does an explicit channel-depth conversion; crop and canvas size retain the existing samples and placement.

UI, MCP and CLI use the same `transform` and `move` commands, reservations, locks and revision guards. With an active selection, use `selection_only:false` to transform the whole layer. Selected-pixel operations continue to edit that region as raster artwork. Live previews contain actual shared-engine pixels, and finishing a gesture produces one undo step.

## Bounded affine skew (unreleased PB-153 slice)

Shared `transform` commands accept optional numeric `skew_x` and `skew_y` angles in degrees, each from -80 through 80, defaulting to zero. Horizontal shear runs first, then vertical shear, then the existing scale/reflection and rotation around the document-space `pivot`. A positive horizontal angle moves the bottom edge right; a positive vertical angle moves the right edge down. Each shear uses the tangent of its angle; sequential shears stay nonsingular even when both angles are 45 degrees. Explicit skew fields use the existing 15-degree grid with `snap:true`. Invalid types and raw bounds reject before snapping.

For example, `{"op":"transform","layer":"LAYER_ID","skew_x":15,"skew_y":-10,"pivot":[100,80],"selection_only":false}` previews and commits through the ordinary shared engine. Whole layers and folders retain native Color/mask originals; linked masks follow Color and unlinked targets retain their existing independent behavior. Editable source definitions receive the same affine placement and rerender only when their existing validation succeeds. Missing installed fonts reject rerendering atomically rather than rasterizing the saved appearance.

Selected raster Color and painted-mask pixels support the same bounded skew. Their polygon and scalar coverage (including feathering and holes) use the same forward placement and inverse source map in one sampling pass. Set `selection_only:false` to transform the whole target while leaving the current selection unchanged. Zero or omitted skew retains existing rotation/scale/selected-pixel behavior and output. Existing dimension, memory, work, lock, reservation and exact-source guards remain in force. PSD/PSB saves use existing retained affine source metadata plus current standard native raster/mask channels and the merged composite; this adds no new Photoshop import compatibility or source format.

## Pending Free Transform session (unreleased)

Open Layer > Free Transform or press Ctrl+T on Windows/Linux or Cmd+T on macOS. Move, Rotate and Scale controls share the existing configured W/E/R bindings while the session owns input. Drag the outline in Move mode, its corner/side handles in Scale mode, or the round rotation handle; numeric controls also provide move, scale, angle, skew and flips. Shift snaps a drag using the established move/angle/scale grids and keeps scale uniform. Releasing a handle or changing modes retains the pending result. Apply or Enter outside a text/IME field commits one shared-engine transaction; Cancel, Escape, focus loss, source replacement/editing or a target interruption discard the preview and preserve current artwork.

The current rendered canvas supplies the preview. Apply waits for the exact current preview; older responses from the same session cannot authorize changed values. Save, close and update restart ask the user to apply or cancel first. Numeric/IME typing owns its keys; completing a numeric field with Enter does not also commit the session. Cancelling a held canvas handle suppresses the old press through release; held destructive-key repeats require a fresh press.

Shared `transform` accepts optional numeric `dx`/`dy` from -100000 through 100000 document pixels, default zero, applied after the linear transform. Values round to whole document pixels; explicit fields use the existing 8-pixel grid with `snap:true`. A strict boolean `fractional_translation:true` explicitly preserves fractional `dx`/`dy` for `transform` within the same raw bounds. Omitted or false keeps the previous arithmetic; `move` refuses the true flag and remains integer placement. Translation, affine placement and selection coverage use one original-sampling pass per target. A session with ordinary movement alone keeps the established `move` command, so saved text can move while its installed font is unavailable. A fractional affine placement is a transform and retains source rerender validation, including missing-font refusal. Whole-target originals, native channels, painted masks, hidden folder children and editable definitions retain their existing shared validation. Existing retained f64 affine matrices and editable-source f32 matrices already store this placement; the command flag is not a new saved-source field or format. Current standard native raster/mask channels and merged composites remain in PSD/PSB saves.

With a selection, the initial target is selected pixels, including skew. Explicitly choose Whole target (keep selection) to apply the pending values to the full target without moving selection geometry. Enter or drag the reference before or after an adjustment. Reference movement alone is presentation only: the pending command and actual rendered pixels stay exact. A later rotation, scale, skew or flip uses that chosen document-space reference while keeping one command per target and one sample of the original selected pixels. The reference follows later Move changes. User values snap before the necessary fractional reference compensation; that compensation is never rounded to an integer move. Reset transform clears the pending values and retains the current reference. The affine controls retain existing renderer precision, budgets and source format without a chain of raster cuts. The projective extension below uses the same pending session and format32 for retained homographies. Modifier-rich Photoshop parity and grid/preset Warp remain unfinished.

Selected skew is a raster edit, like the existing selected move/scale/rotation: selected regions establish the next raster baseline, while untouched regions and native channel depth are preserved. Linked Color/Mask, independent Color or Mask/paint-step targets, hidden folder children and multiple selected roots keep their existing target semantics. Multiple roots share one original document-space selection. Editable text/vector pixels require explicit rasterization; unsupported mask-effect stacks remain rejected. Destination reservations enclose the actual f32 polygon/coverage geometry, and the selection itself remains reserved. A cancelled, invalid, locked, reserved, stale or over-budget request cannot publish partial shared artwork. This adds no PSD source format or Photoshop feature-import support; saved standard channels and merged composites remain current.

## Shared projective placement (unreleased PB-153 slice)

`transform` accepts an optional strict `projective` object with `rect:[left,top,right,bottom]` and `quad:[[TLx,TLy],[TRx,TRy],[BRx,BRy],[BLx,BLy]]`. Both use document coordinates. The rectangle must have positive dimensions and the quad must be convex, retain that corner order and winding, and remain within the existing coordinate limits. Unknown fields, invalid numeric types, folds, singular or unstable maps reject. Use the existing mirror flags for a reflection, rather than reversing the quad. `move` rejects a projective field.

For example, `{"op":"transform","layer":"LAYER_ID","selection_only":false,"projective":{"rect":[0,0,16,12],"quad":[[24,3],[32,2.4],[32,12],[24,15]]}}` maps the four original rectangle corners to the given corners. The projective map P runs first, then the existing affine A (horizontal/vertical skew, scale/reflection, rotation and posttranslation), in one A×P source-sampling pass. An explicit `pivot` controls A; otherwise a nonidentity projective command uses the source rect center, including multiple roots or hidden folder descendants. `snap:true` resolves the existing affine fields, and does not round supplied quad coordinates. Omitted or exactly identity projective placement takes the unchanged legacy affine path, including its pivot, arithmetic and serialized fields.

Whole raster Color and each painted mask retain one native original. Affine gestures, storage expansion and mask reframing after a projective gesture compose with that original placement instead of baking intermediate pixels. The complete composed original frame must stay on one safe side of the projective horizon, including transparent hidden RGB and retained off-frame mask samples; a valid visible quad alone is insufficient. Native8/16 resampling and existing size, document memory and 128-million-output-sample limits still apply. These limits do not establish a bound on total process memory.

Selected raster Color, linked masks, independent Color/Mask or an explicit paint step use the same document-space inverse for native samples and scalar soft/hole coverage. As with selected affine edits, only changed rasters establish a new baseline. Hidden raster folder descendants share one original selection and map. Editable text/vector sources, including hidden children, and adjustment children reject projective Color changes with explicit native-precision rasterize guidance; the existing editable-source mask and unsupported mask-effect protections remain. No source or history is committed on a failed, stale, reserved or locked request. Live engine previews and final commands share the same geometry, native samples and reservations.

Observation retains the existing affine `matrix` and adds `projective` only when needed: nine row-major coefficients mapping the original local frame, applied before the affine matrix. No OS paths or pixel samples are added to observation. Supplementary PSD/PSB source format **32** is required if any Color or mask original contains a projective map. Format-31 and earlier claims cannot admit that data; unsupported/future/malformed sources remain protected and the current standard native raster/mask channels and merged composite remain usable. This is PeerBrush editability metadata, not a claim of Photoshop Smart Object, Distort or Perspective interchange.

## Coarse control-grid Warp (unreleased PB-153 slice)

`transform.warp` accepts exactly `{"rect":[left,top,right,bottom],"points":[[x0,y0],...,[x8,y8]]}`. Nine document-space points are ordered left-to-right across the top, middle and bottom rows. The alternative strict form `{"rect":[left,top,right,bottom],"preset":"arc","amount":0.2}` generates that same canonical grid; `arc`, `bulge` and `flag` support amounts from -0.25 through 0.25. Unknown fields, malformed numbers and `move` with a Warp field reject. Omission or an exactly identity grid follows the unchanged legacy arithmetic, scopes and source serialization.

This is a coarse 3×3 grid: the four cells each use their top-left to bottom-right diagonal, producing eight affine triangles. Adjacent triangles meet continuously, but their slopes can differ at seams. This does not implement smooth Bezier patches, arbitrary mesh topology or Photoshop's Warp presets/metadata. Nodes may move only while triangles remain positive, conditioned and non-overlapping. The grid input rectangle must enclose the complete targeted original and its interpolation support, including hidden RGB and off-frame painted masks. There is no discontinuous identity outside the grid and no extrapolation that discards hidden content. A shared target-domain query initializes the UI from these complete sources rather than visible layer bounds; engine admission still validates the actual command.

The command evaluates **A×P×W**: grid W, then optional projective P, then existing affine A and translation. An explicit pivot takes precedence; otherwise the projective rectangle center wins, then the Warp rectangle center. Snap resolves the existing affine values and leaves supplied control points exact. Mixed Distort/Perspective controls refer to their explicit projection plane rather than pretending a bent subject corner is a projection-rectangle corner. Changing modes retains the same command and actual shared-engine result.

Whole Color and painted masks retain one native original and an exact chain of at most **16** Warp stages. Each stage stores its preceding row-major homography and canonical grid; the final affine/projective placement follows the chain. Later affine/projective edits, storage expansion and mask reframing remain placements and consume no grid stage. Inverse traversal validates every stage and samples the original once, preserving native8/16 and hidden channels without intermediate raster cuts. Outside-grid or horizon failure remains invalid until final sampling, so an intermediate transparent sentinel cannot turn into valid pixels in an earlier stage. A seventeenth Warp rejects atomically with actionable Undo/cancel guidance; it never silently resets or bakes retained originals.

Selected raster edits keep their established baseline behavior. Their polygon edges split at every crossed source-triangle seam before mapping, so bent boundaries are retained; Color/mask center clipping and bilinear scalar feather/hole coverage keep their existing distinct roles. Each polygon is limited to 8192 vertices and 131072 seam candidates before expansion. Output area × affected rasters × `(1 + 9 × stages + vertices)` must not exceed 128 million mapping-work units before allocation. Nine conservatively includes the eight triangle probes and each stage's preceding homography. Existing document native-raster memory, 8192-edge, 32-megapixel and other transform limits remain; these are not a total process-memory ceiling. Conservative complete-domain bounding can reject an unusual otherwise-valid composition rather than drop pixels.

Editable text/vector sources and adjustment folder children require explicit native-precision rasterization. Existing editable-source mask and unsupported mask-effect restrictions remain. Hidden raster children, linked/unlinked masks, explicit paint steps, multiple roots, preview, stale-source checks, locks, destination/selection reservations, one transaction and undo/redo use the shared engine. A failed batch cannot publish a partial document.

Supplementary PSD/PSB source format **33** is required when any Color or painted-mask original contains Warp stages. Observations add `warp_stages` only for those retained sources, with no raster samples or paths. Current standard native raster/mask channels and the current merged composite are still written; malformed, downgraded and future sources reopen protected from the standard merged data. Clipboard and recovery carry the same strict native source format. Grid metadata and retained tiles count against existing document/proposal budgets. This is PeerBrush editability, not Photoshop nonlinear-transform interchange.

Prepared tests cover independent piecewise inverse and seam oracles, native8/16 Color/linked and independent masks/paint steps, soft/hole coverage and exact original remainders, hidden folders, composed and successive maps, protocol reservations and atomic failures, 16/17-stage limits, identity compatibility, clipboard validation, and PSD/PSB source33/current standard channels/merged and PNG readback.
