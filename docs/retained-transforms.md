# Transforms that retain original pixels

Whole-layer rotation, scaling and skew retain the original native raster and an accumulated affine placement. Every preview and finished gesture samples that original, so shrinking then enlarging or rotating repeatedly does not repeatedly filter the previous result. Exact inverse placement restores native words, including hidden RGB, without an 8-bit editing copy. Move changes document placement without resampling. Hidden folder descendants use the same operation and pivot.

Each painted mask step retains its own original and placement. Effects, mask operations, hierarchy and blend settings remain editable. Changing only a mask preserves the color original; painting color preserves unaffected mask originals. Pixel editing establishes a new baseline from the current appearance for the changed raster. This includes painting, clone/heal, fills, direct pixel adjustments, image replacement, and selected-pixel transformations. Undo restores the preceding pixels and originals together. Image size explicitly resamples the document and establishes new raster baselines, as does an explicit channel-depth conversion; crop and canvas size retain the existing samples and placement.

UI, MCP and CLI use the same `transform` and `move` commands, reservations, locks and revision guards. With an active selection, use `selection_only:false` to transform the whole layer. Selected-pixel operations continue to edit that region as raster artwork. Live previews contain actual shared-engine pixels, and finishing a gesture produces one undo step.

The UI holds both scale axes equal while Shift is down and returns to the chosen axis when Shift is released. Snapping applies to the same layer, folder, mask or selected-pixel target as a free transform, at the original native depth. Pan/zoom does not change the move grid. Small scales snap to at least 0.1; existing transform size/work budgets still apply.

Unreleased selection corrections (PB-110): native copy gives an active pixel selection precedence over the last layer-row click. Selected copies retain exact coverage, holes, feathering, document coordinates and native channels. A selected folder transforms only selected pixels in its raster descendants, including hidden children, using one original selection and pivot. Folder masks and hierarchy stay in place for Color selection transforms; text/vector and adjustment children require explicit rasterization. Multiple selected layers/folders share the same selection baseline in both live previews and committed edits. Selection transforms honor reservations on the selection geometry as well as affected layers. Whole-layer copy remains available after deselecting. With an area selected, Ctrl/Cmd+X copies the active layer's selected content before clearing only its covered pixels; Ctrl/Cmd+V creates a new paint layer at the retained document coordinates. Feathered edges, holes and native 8/16-bit samples are retained. Clipboard write failure, locks, reservations or an intervening edit preserve the source; a successful copy remains available if the guarded erase is refused. Cut and Paste have separate undo steps. These selected Cut/Paste updates are unreleased.

Each applies once around the selected pixels or selected roots' common center, with one undo step. Selecting both a folder and its descendant does not transform the descendant twice. Color actions include hidden descendants and attached masks; the selected Color/Mask target follows its mask link state as described below. An explicit paint step can transform independently after unlinking. Whole-mask transformations keep their original samples, including off-frame samples, for later inverse edits. Windows copy retains a message-only clipboard owner on the worker thread and services its messages while idle. Image writes publish a native-depth PNG and a standard display-depth DIBV5 bitmap with explicit alpha. Encoding finishes before opening and clearing the clipboard. Failed writes do not replace the internal buffer or delete source layers. Shrinking or moving artwork changes its content bounds, while the document canvas remains available for raster editing. Painting, masks, smudge, clone/heal, fills, shapes and gradients can reach outside the transformed content. When needed, the engine expands sparse layer storage to include the canvas and keeps existing off-canvas samples. Pixels are copied at their original channel depth, including hidden RGB; mask steps and local liquify controls move with the storage frame. Unchanged transform originals retain their original samples and receive only a coordinate translation. Active selections and explicit masks still apply. Undo restores the preceding storage frame and originals together. Layers whose storage does not cover the canvas use the ordinary shared-engine stroke preview until expansion, avoiding a fixed incremental clip.

Observation exposes `transform_source` for each retained color raster and painted mask step: original width, height, bit depth, source bytes and the affine matrix `[a,b,c,d,tx,ty]` mapping original local coordinates to the current local frame. Sample data stays in the document, not in observation responses.

PSD saves contain current standard layer raster/mask channels and a current merged composite. Supplementary PeerBrush source format 9 preserves originals for later edits and inverse transforms after reopening. Photoshop receives the current raster appearance; this does not create Photoshop Smart Objects. Earlier PeerBrush readers protect these newer documents as read-only.

Original tiles use copy-on-write snapshots and are counted alongside current raster projections in the 512 MiB document budget. Transform dimensions retain the 8192-edge/32-megapixel limits, with a 128-million-sample work bound per layer command. Invalid, reserved, locked or over-budget requests roll back atomically. Nested originals are refused; derived preview caches remain outside history and saved source definitions.

## In-progress selection shortcuts (unreleased)

Clipboard, Delete and configured Move/Rotate/Scale shortcuts require a completed selection gesture. While a canvas selection press/drag is held, or before its release in the same input frame, the workspace asks for release and an explicit retry. It retains no queued clipboard or destructive command. Shortcuts arriving after release continue using the newly committed native coverage; a rejected selection transaction prevents replay. Text entry, settings dialogs and polygon/magnetic path editing retain their existing input handling. Escape cancels an active selection press through release, preventing a later wand click or rectangle commit; a new press starts normally. Added native8/16 input coverage for held gestures, retry, cancellation, exact source preservation and undo passed combined QA.


Unreleased mask linking (PB-152): new masks default to linked. Click the chain beside a mask thumbnail or the selected Color/Mask controls to link or unlink it. `mask.link` takes `layer` and a strict boolean `linked`; observation reports that state. Linked move/rotate/scale commands transform Color and Mask together, including an active selection. Unlinked Color leaves mask samples fixed in document coordinates; unlinked Mask leaves Color fixed. Without `step`, a whole-mask command transforms all paint steps. An explicit `step` targets one unlinked paint step. Locks, reservations, document/revision guards, actual previews and one-gesture undo remain shared with MCP/CLI. Selective task undo preserves later human work.

Independent Color and selected linked transforms currently support fill/paint mask stacks. Other mask-effect combinations reject atomically instead of silently rasterizing. Unlinking permits the established selected-Color path or an explicit paint-step transform. Whole linked layer transforms retain their existing supported mask behavior; folder transforms retain hierarchy and hidden children. Retained mask originals preserve samples outside the current Color frame for inverse operations and save/reopen.

Source format 29 retains explicit link choices alongside ordinary native PSD/PSB raster/mask channels and the current merged composite. Older PeerBrush readers protect that newer source format. Legacy native sources and supported standard raster masks start linked. Photoshop link-state import/export and receiving-application behavior are not implemented or verified; another editor may use its own link state. Unlinked saves report this limitation and require the existing source-bound editability-loss acknowledgement. No Photoshop link flag is guessed from its separate coordinate flags.

Adobe's [PSD specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/) describes mask coordinate flags separately and notes historical interactions between mask linking and effect compositing. PeerBrush does not infer verified Photoshop link interchange from those fields; the standard-mask importer retains its existing unsupported-flag protection.

## Bounded affine skew (unreleased PB-153 slice)

Shared `transform` commands accept optional numeric `skew_x` and `skew_y` angles in degrees, each from -80 through 80, defaulting to zero. Horizontal shear runs first, then vertical shear, then the existing scale/reflection and rotation around the document-space `pivot`. A positive horizontal angle moves the bottom edge right; a positive vertical angle moves the right edge down. Each shear uses the tangent of its angle; sequential shears stay nonsingular even when both angles are 45 degrees. Explicit skew fields use the existing 15-degree grid with `snap:true`. Invalid types and raw bounds reject before snapping.

For example, `{"op":"transform","layer":"LAYER_ID","skew_x":15,"skew_y":-10,"pivot":[100,80],"selection_only":false}` previews and commits through the ordinary shared engine. Whole layers and folders retain native Color/mask originals; linked masks follow Color and unlinked targets retain their existing independent behavior. Editable source definitions receive the same affine placement and rerender only when their existing validation succeeds. Missing installed fonts reject rerendering atomically rather than rasterizing the saved appearance.

Selected raster Color and painted-mask pixels support the same bounded skew. Their polygon and scalar coverage (including feathering and holes) use the same forward placement and inverse source map in one sampling pass. Set `selection_only:false` to transform the whole target while leaving the current selection unchanged. Zero or omitted skew retains existing rotation/scale/selected-pixel behavior and output. Existing dimension, memory, work, lock, reservation and exact-source guards remain in force. PSD/PSB saves use existing retained affine source metadata plus current standard native raster/mask channels and the merged composite; this adds no new Photoshop import compatibility or source format.

shortcut: projective distort/perspective and control-grid Warp remain PB-153 work. Add those only with shared live preview, coherent Apply/Cancel history and their own native acceptance.

## Pending affine Free Transform session (unreleased)

Open Layer > Free Transform or press Ctrl+T on Windows/Linux or Cmd+T on macOS. Move, Rotate and Scale controls share the existing configured W/E/R bindings while the session owns input. Drag the outline in Move mode, its corner/side handles in Scale mode, or the round rotation handle; numeric controls also provide move, scale, angle, skew and flips. Shift snaps a drag using the established move/angle/scale grids and keeps scale uniform. Releasing a handle or changing modes retains the pending result. Apply or Enter outside a text/IME field commits one shared-engine transaction; Cancel, Escape, focus loss, source replacement/editing or a target interruption discard the preview and preserve current artwork.

The current rendered canvas supplies the preview. Apply waits for the exact current preview; older responses from the same session cannot authorize changed values. Save, close and update restart ask the user to apply or cancel first. Numeric/IME typing owns its keys; completing a numeric field with Enter does not also commit the session. Cancelling a held canvas handle suppresses the old press through release; held destructive-key repeats require a fresh press.

Shared `transform` accepts optional numeric `dx`/`dy` from -100000 through 100000 document pixels, default zero, applied after the linear transform. Values round to whole document pixels; explicit fields use the existing 8-pixel grid with `snap:true`. A strict boolean `fractional_translation:true` explicitly preserves fractional `dx`/`dy` for `transform` within the same raw bounds. Omitted or false keeps the previous arithmetic; `move` refuses the true flag and remains integer placement. Translation, affine placement and selection coverage use one original-sampling pass per target. A session with ordinary movement alone keeps the established `move` command, so saved text can move while its installed font is unavailable. A fractional affine placement is a transform and retains source rerender validation, including missing-font refusal. Whole-target originals, native channels, painted masks, hidden folder children and editable definitions retain their existing shared validation. Existing retained f64 affine matrices and editable-source f32 matrices already store this placement; the command flag is not a new saved-source field or format. Current standard native raster/mask channels and merged composites remain in PSD/PSB saves.

With a selection, the initial target is selected pixels, including skew. Explicitly choose Whole target (keep selection) to apply the pending values to the full target without moving selection geometry. Enter or drag the reference before or after an adjustment. Reference movement alone is presentation only: the pending command and actual rendered pixels stay exact. A later rotation, scale, skew or flip uses that chosen document-space reference while keeping one command per target and one sample of the original selected pixels. The reference follows later Move changes. User values snap before the necessary fractional reference compensation; that compensation is never rounded to an integer move. Reset transform clears the pending values and retains the current reference. This retains existing renderer precision and budgets; it does not add a chain of raster cuts or a new saved-source format. Projective distort/perspective, modifier-rich Photoshop parity and grid/preset Warp remain unfinished.

Selected skew is a raster edit, like the existing selected move/scale/rotation: selected regions establish the next raster baseline, while untouched regions and native channel depth are preserved. Linked Color/Mask, independent Color or Mask/paint-step targets, hidden folder children and multiple selected roots keep their existing target semantics. Multiple roots share one original document-space selection. Editable text/vector pixels require explicit rasterization; unsupported mask-effect stacks remain rejected. Destination reservations enclose the actual f32 polygon/coverage geometry, and the selection itself remains reserved. A cancelled, invalid, locked, reserved, stale or over-budget request cannot publish partial shared artwork. This adds no PSD source format or Photoshop feature-import support; saved standard channels and merged composites remain current.

Free Transform scale handles retain axis signs when crossing the opposite anchor. The existing positive scale magnitude combines with an axis mirror, including proportional corner scaling and Shift side scaling. Crossing back restores the starting mirror flags. Prior rotation/skew and a moved reference point remain in the same shared transform command; the native8/16 renderer, one guarded Apply and ordinary PSD/PSB retained-source format remain in use. The existing minimum/maximum scale limits still apply. This crossing-handle slice is unreleased and awaits combined/runtime/native visual acceptance; it does not add perspective, distort or control-grid Warp.

Unreleased direct skew: choose Skew in the same Free Transform session. Drag a top/bottom X handle or left/right Y handle to change that shear about the current reference. Existing rotation, scale and mirrors determine the visible drag direction; the shared order remains horizontal shear, vertical shear, scale/reflection, rotation and posttranslation. Shift snaps to the existing 15-degree grid, and the existing ±80-degree bounds still apply. An edge on its reference axis stays fixed; use the opposite edge or move the reference. Returning a handle to its starting position restores the exact starting command. Handle release and switching back to Move/Rotate/Scale keep the operation pending, with actual shared-engine pixels and one guarded Apply/undo. No new source format, projective map or grid Warp is added. Native8/16 analytic and real-control selected Color, linked/unlinked painted masks, explicit paint-step, hidden folder, cancellation, reservation and PSD/PSB fixtures are prepared; combined execution and native visible interaction remain pending.
