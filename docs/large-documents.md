# Large-document loading and derived caches

Native Perspective, Distort and Warp on sparse layers and masks skip output tiles whose inverse sampling bounds contain no stored source tiles. The bounds include bilinear neighbors. Warp checks each retained grid from the output back to the source. Tiles with uncertain bounds use the regular sampler. Whole-layer and mask transforms charge the shared work allowance for their actual raster work, including each retained Warp stage. The operation still checks cancellation, backing ownership and write admission. Dense Warp and selected-pixel Warp remain bounded. Native 8-bit and 16-bit seam coverage is in source, with desktop verification pending.

Selected-pixel Warp charges for the cut and destination work, including grid probes and resampling feathered coverage. A small selection can be warped on a large layer within the shared work budget. Perspective, Distort and Warp can skip destination tiles when conservative inverse bounds prove that no stored paint or selection coverage can contribute. The native source includes a 16,000 × 16,000 regression for preview, unrelated pixels and Undo at both channel depths.

Native Selection Overlay, Mask and Cutout previews check cancellation and live session state while projecting rows from pinned coverage. Source reads and completed stripe handoffs still check the backing inventory. This avoids inventory scans on every already-pinned row during large-canvas selection previews.

Native canvas previews also use in-memory session checks while scanning tile indexes, copying retained rows, hashing or converting texture pixels, and waiting for the renderer to release upload buffers. The worker validates backing ownership during source reads and before returning a complete texture candidate. Uploads remain private until the candidate passes the existing display checks. Large-canvas latency has yet to be measured for this change.

Native canvas previews read paint, mask and live layer-effect inputs in batches of up to 16 tiles from the same backing file. The batch reader shared with Photoshop saves checks ownership before and after each batch and verifies the digest of each newly read tile. Rendering uses the original 8-bit or 16-bit samples, and cancellation is checked during reads and digest work.

Native Magic Wand, Quick Selection and Object region size their source bands to the search width and the existing read budget. Each band stays within one tile row. Noncontiguous matching copies complete rows from those pinned tiles and compares the same rendered RGBA samples. Wide-search runtime verification is pending.

When Add, Subtract or Intersect combines a sampled selection with prior coverage, the native engine reuses a bounded band aligned to the prior mask’s tile rows. It reads exact coverage bytes and fills areas outside a cropped mask with zero. Rectangular selections fill their covered span directly. Runtime verification is pending.

Path to Mask stages coverage within the path bounds and feather margin. Add Mask and Mask from Selection can read plain rectangular selections directly, and replacement masks consume exact coverage rows in the target layer’s frame. The appended grayscale step retains opaque alpha, including where coverage is zero.

Native mask replacement, intersection and refinement reuse stored opaque black tiles where selection or refined coverage is absent. Partial tiles retain zero padding outside the logical mask frame.

Refine Layer Mask keeps the edge guide aligned with an offset layer’s mask. For layers extending beyond the canvas, the guide renders the visible overlap and pads areas outside the canvas with transparency. The mask keeps its native channel depth.
