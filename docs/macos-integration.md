# macOS installed bundle and document opening

Unreleased v0.3 bundles include `PeerBrush.app/Contents/Resources/PeerBrush.icns`, the GPL license, `THIRD_PARTY_NOTICES.md` and all verified dependency/font/runtime license files before signing seals the app. These remain available after dragging only the app to Applications. The matching source archive and public support documentation remain alongside the app in the distribution; they are not duplicated inside the app. Keep that corresponding source available with every distributed binary.

The committed ICNS uses the unchanged branded PNG from `assets/peerbrush-logo.png`, resized to the standard 1024-pixel icon master with smaller ICNS representations. It is a source asset; package builds do not require an image-generation library. Native CI decodes it with Apple's `sips`.

For canonical internal `A.B.C-dev.N` candidates, both Apple version fields contain the numeric `A.B.C` core, while `PeerBrushDevelopmentVersion`, the release manifest, matching Cargo source and application UI retain the full version. This follows Apple's numeric [bundle-version](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundleversion) and [short-version](https://developer.apple.com/help/glossary/version-number/) formats. These unsigned development candidates require manual replacement and have no development update feed; distinct iterations can share the same numeric bundle version. Every prerelease is rejected by Developer ID ZIP/DMG signing before provider access. Stable `0.30.0` metadata remains unchanged. shortcut: this numeric projection supports internal candidates only; define a separate monotonic build-number policy before distributing prerelease updates.

`CFBundleDocumentTypes` offers PeerBrush as an Editor for Photoshop PSD (`com.adobe.photoshop-image`) and PSB (an imported extension-based image type). Both use `LSHandlerRank=Alternate`. This makes the installed app available for user selection through Open With. PeerBrush does not set the default editor, replace an existing user's association, or register itself through a launch-time shell command. Users can choose Open With or use Finder's Get Info → Open with → Change All themselves. Registering a bundle can affect which apps Finder lists; verify actual Launch Services behavior on a clean native test account before release. Apple's [handler-rank documentation](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundledocumenttypes/lshandlerrank) defines Alternate as a secondary handler.

Finder delivers documents with Open Documents Apple Events rather than ordinary command-line arguments. The installed handler uses [NSAppleEventManager](https://developer.apple.com/documentation/foundation/nsappleeventmanager), retaining winit's application delegate. A main-thread guard owns the handler until the native event loop ends. It decodes the complete bounded native file-reference list using filesystem representations, queues it through the existing activation path and requests a repaint. Malformed, non-file or excessive lists fail as a whole. Existing project loading still decides when files may open: active gestures, recovery, reservations, conflicting sources, unsupported Photoshop content and unsaved projects retain their protections. The native callback never replaces or saves a document itself.

Apple's [Open Documents handler guide](https://developer.apple.com/library/archive/documentation/AppleScript/Conceptual/AppleEvents/responding_aepg/responding_aepg.html) describes a list of native aliases, so accepting only constructed file URLs is insufficient compatibility evidence. The unreleased boundary accepts an original Apple Event list (`typeAEList`, `list`) containing original [native file-reference descriptors](https://developer.apple.com/documentation/coreservices/apple_events/1542788-descriptor_type_constants): file URLs (`typeFileURL`, `furl`), Carbon aliases (`typeAlias`, `alis`) and bookmarks (`typeBookmarkData`, `bmrk`). It checks each original [descriptor type](https://developer.apple.com/documentation/foundation/nsappleeventdescriptor/descriptortype), allows 1–16 items and limits each original or converted reference to 64 KiB. Plain paths, textual file/HTTPS URLs, records, object specifiers, unknown types and mixed invalid lists are rejected before any file queues.

Only original `furl` descriptors reach [fileURLValue](https://developer.apple.com/documentation/foundation/nsappleeventdescriptor/fileurlvalue), which can otherwise coerce text. Native alias bytes are converted to bookmark data through [CFURLCreateBookmarkDataFromAliasRecord](https://developer.apple.com/documentation/corefoundation/cfurlcreatebookmarkdatafromaliasrecord(_:_:)); alias and bookmark resolution then uses `NSURL` with [withoutUI](https://developer.apple.com/documentation/foundation/nsurl/bookmarkresolutionoptions/withoutui) and [withoutMounting](https://developer.apple.com/documentation/foundation/nsurl/bookmarkresolutionoptions/withoutmounting). Resolution failures are reported without prompting, mounting a volume or rewriting stale reference data. The result must still be a local absolute file URL, retaining its filesystem bytes. No general descriptor coercion or string fallback is used. Direct FSRef (`fsrf`) and FSSpec descriptors remain unsupported; adding FSRef requires a documented safe conversion and a real native fixture, not a guessed structure layout. Actual Finder descriptor delivery remains pending native acceptance.

## Verification

Portable package tests check the exact committed icon, installed licenses/notices, PSD/PSB declarations and Alternate rank, including rejected tampering. Exact-source archive inspection requires the resource layout for source revisions containing the icon. Historical archives from earlier source revisions retain their original layout rules. Existing signing tests verify resources cannot change unnoticed while an app is signed or stapled.

On macOS, `cargo run --locked --example macos_activation` creates existing synthetic files in an exclusive private temporary directory, including spaces, Unicode and literal `%#?` punctuation. It requires OS-created alias and bookmark fixtures as well as original file URLs, asserts their original descriptor types and resolved paths, and cleans up its own temporary files. Empty, malformed, truncated, oversized, excessive, unsupported and mixed invalid events must return an error through the actual same-process handler without queuing even the valid entries. The example compares dirty document/source/history state and the existing application delegate, then sends a mixed valid native-reference event that may only queue. These new alias/bookmark fixtures require a native macOS CI run; earlier `furl`-only component results do not validate them.

The example runs before eframe/winit starts and does not prove delivery with its running delegate. CI also uses `sips` to decode the committed icon. These component checks require no certificate, notarization profile, Finder automation or default-app changes. They are not installation or Finder acceptance.

Before marking this slice accepted, test the final signed/notarized distribution on a disposable macOS account: mount the image, drag only PeerBrush.app to Applications, eject the image, open the app under quarantine, inspect its Dock/Finder icon and bundled licenses, and select PSD and PSB through Finder Open With both when closed and already running. Test filenames with spaces/Unicode, multiple selections, another default editor, dirty work, an active gesture, recovery and conflicting sources; confirm the default editor is retained unless the user changes it. Repeat after an upgrade and verify a fresh launch after logout/restart. Record actual OS/app versions and results. These manual checks remain pending until run on native macOS.

## Guarded native Quit (unreleased)

Native Quit is routed through the ordinary source-bound Save / Don't Save / Cancel review. Startup adds only the absent applicationShouldTerminate: method to the exact pinned winit delegate class, keeping the same delegate object and all existing methods. The callback always returns NSTerminateCancel and queues a coalesced presentation signal; it does not lock an engine or workspace. The existing UI checks unfinished drafts, and the shared final close checks every reviewed source and active project/workspace file operation before closing anything. Ordinary close still cancels a pending load. An existing or unknown termination handler aborts native startup before editable work begins.

The new macos_quit example is prepared for the macOS CI component step. It invokes the real terminate: selector in an owned child with private synthetic native 8/16-bit projects, checks delegate identity and existing method implementations, cancels a dirty close review, saves both projects, and requires normal eframe return plus a bounded completion receipt. The callback is also invoked while an engine is locked. Portable UI/engine fixtures cover late file operations, source changes, and unfinished drafts. These checks have not run for this change yet; native AppKit delegate delivery and actual installed workspace acceptance remain unverified.

The native component starts the existing application server in its private temporary state directory; it does not connect an external client or change user preferences. Force termination and forced system shutdown are outside ordinary Quit review.

This human Quit path permits an explicit Don't Save decision. A future verified updater must use finish_update_exit and its additional no-discard, no-loading and no-code-work guards, with the live UI checks, before any installer handoff. The guard does not activate Sparkle, configure a feed/key, or qualify update installation/recovery.
