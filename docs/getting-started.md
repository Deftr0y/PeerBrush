# Getting started

PeerBrush 0.30.0 is an unpublished release candidate. For the earlier published builds, use the [Windows Store listing, MSIX 1.25.0.0](https://apps.microsoft.com/detail/9PNR6T1Q2ZL9) or [macOS and Linux release 0.26.0](https://github.com/Deftr0y/PeerBrush/releases/tag/v0.26.0). Launch PeerBrush and use the File menu to create, open, import, export or save a project.

Unreleased: **File → About PeerBrush…** shows this running copy's version and source revision from its embedded build metadata. Development/prerelease, dirty local and unknown-source builds are identified. This information is independent of available downloads and does not check the network or change preferences, artwork or undo history.

Unreleased: **File → New canvas** and the tab strip's **+** suggest a readable clipboard image's dimensions once per opening. The image is not pasted and the clipboard is not changed. Editing either dimension keeps your manual values; unavailable clipboard content keeps the current dimensions. Unsupported sizes are explained before creation. **Create canvas** opens a separate blank 8-bit or 16-bit project; **Cancel**, Escape and the dialog's close button keep existing artwork and history intact.

For the Windows 0.25 folder, double-click **Start PeerBrush.cmd**. It uses a separate `PeerBrush-0.25.0` workspace under Local AppData. Existing project files remain at their original locations; earlier workspaces and recovery files are not moved automatically. The macOS package contains **PeerBrush.app**; the Linux package contains an executable `peerbrush`. See [package verification](release-packages.md) for checksums, signing status and platform requirements.

**First launch:** PeerBrush asks whether to become your PSD/PSB editor. Choose **Use PeerBrush** to request the change or **Not now** to retain your current defaults. The choice is remembered in your per-user settings. Windows opens its Default apps settings for the final selection; macOS may ask for confirmation. On macOS, install first: open the DMG, drag PeerBrush onto Applications, eject the disk image, then open PeerBrush from Applications.

**File → PSD/PSB default editor…** explains how to choose PeerBrush for files opened from your file manager. On Windows, **Open Windows Default apps** opens the system's default-app settings; choose `.psd` and `.psb` separately. A portable copy does not register itself there: use a registered installation or Explorer's **Open with → Choose another app** to locate `peerbrush.exe`. See [Microsoft's Default apps guidance](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings).

On macOS, keep PeerBrush.app in Applications, then use Finder **Get Info → Open with → Change All** for each file type, as described in [Apple's file-opening guidance](https://support.apple.com/guide/mac-help/choose-an-app-to-open-a-file-on-mac-mh35597/mac). The signed app declares PSD and PSB document handlers. On Ubuntu 24.04's Files desktop, use **Open With…**, choose PeerBrush, enable **Always use for this file type**, then **Open**; this control is present in the [GNOME 46 chooser](https://github.com/GNOME/nautilus/blob/gnome-46/src/resources/ui/nautilus-app-chooser.ui). Older desktops may use **Properties → Open With → Set as default**, as described in [Ubuntu's guidance](https://help.ubuntu.com/stable/ubuntu-help/files-open.html). Missing Linux desktop registration needs installation. PeerBrush applies no default itself, and opening or closing this guidance leaves artwork and undo/redo history intact. **File → Open PSD/PSB** remains available regardless of OS registration.

The first canvas is transparent. Use the brush, eraser, fill, gradient, rectangle, ellipse, move, rectangle selection, eyedropper, and pan tools. Scroll or **Alt + right-mouse drag** to zoom around the cursor; **middle-mouse drag** or Space-drag to pan. **F** frames an active selection with a small margin, or centers and fits the full canvas when nothing is selected. The frame icon does the same.

Create regular layers or folders in the layer panel. Creating a folder, or pressing **Ctrl/Cmd+G**, gathers the selected layer roots into it, preserving their order and children. Click anywhere on a row to select it; use its eye button to toggle visibility. Drag the row or its dotted grip to reorder. The held row follows the pointer, neighboring rows animate into place, and the canvas previews the new order before release. Connected tree branches and indented content show which layers belong inside each folder, including nested folders. Visibility controls stay aligned. Expand or collapse groups with the arrow. Right-click anywhere inside a layer row, including its name, thumbnails, eye or folder arrow, for duplication, locking, masks, group membership, and deletion. Without a pixel selection, **DEL** deletes selected roots and their children in one undo step, respecting locks and reservations. Text inputs and unfinished polygon/magnetic paths keep their normal Delete behavior. Double-click a layer name to rename it directly in the row. Enter or clicking away finishes the rename; Escape cancels it. No popup or confirmation is needed. Choose **Merge layers** or press **Ctrl/Cmd+Shift+G** to merge adjacent layers or flatten a folder in one undo step. **Ctrl/Cmd+E** selects Eraser; its customizable tool binding (D by default) remains available. Layers with backdrop-dependent blends should be grouped and the folder merged to preserve their internal blend results.

Click the content thumbnail to paint pixels. Click the mask thumbnail to paint grayscale. The two overlapping swatches at the bottom left set foreground and background colors. **X** swaps them; mask colors remain independent from artwork colors. Click a swatch for the hue and saturation picker, opacity, and exact HEX entry (`RGB`, `RRGGBB`, or `RRGGBBAA`). Arrow keys adjust the focused picker control. Mask swatches use a grayscale value control. Alt-click isolates a mask; Shift-click toggles it. The mask stack supports paint, fill, invert, levels, feathering, curves, Gaussian blur and tonal adjustments. Select a paint step to edit it; use Add effect to extend the stack.

Save working documents as PSD and export PNG. Unreleased PB-104 also opens/drops PSB projects and saves `.psb` destinations at native 8/16-bit depth under the same supported-subset and size limits. Import [supported raster and SVG formats](image-import.md) as layers, or **drop images onto the canvas**. Supported static SVG/SVGZ keeps editable markup and placement; unsupported visuals report an error. Animated/multipage files and icon variants offer an explicit content choice. Unreleased PB-120: Open also creates projects from supported PNG, JPEG and other images at their original dimensions and native 8/16-bit precision. Multi-content files require an explicit frame, page or icon choice. Image projects start unsaved; save their editable work as PSD/PSB. Original image files remain protected while open. New/Open and dropping one PSD create another project tab, preserving existing work. Unreleased PB-119: drop one supported image, PSD or PSB onto the tabs area to open a new project. The highlighted strip identifies this destination; image drops onto the canvas continue to add layers. Multi-file drops onto the tabs area report that one file is required. Each tab has its own undo, selections, view, dirty marker and save destination. Ctrl/Cmd+S saves the active project; Ctrl/Cmd+O opens another; Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z redoes.

Copy layers or folders, switch tabs and paste to transfer their editable trees. Drag selected layer roots onto another tab to see the actual destination before dropping; hold Shift to move rather than copy. A move creates an independent undo step in each project. Native16 sources promote an 8-bit destination instead of narrowing the artwork. Protected Photoshop sources need an explicit compatible copy before editable tree transfer. See [projects and background AI work](projects.md).

Click a layer row to work with whole layers. **Ctrl/Cmd+J** duplicates the selected layers or folders; **Ctrl/Cmd+C**, **X**, and **V** copy, cut and paste them with their editable masks, effects, children and transforms. Cut removes content only after the clipboard write succeeds. A failed or stale copy cannot delete your work.

Click the canvas to work with pixels. **Ctrl/Cmd+C** copies the active layer's selection, including its visible color effects and mask. A rotated selection clips copied pixels to its exact shape. **Ctrl/Cmd+Shift+C** copies the visible composite. **Ctrl/Cmd+V** also accepts images copied in another application. A PeerBrush pixel copy retains its position; an external image is centered. Paste uses the selected folder or the selected layer's folder. At the top level it creates a folder containing the original and pasted content. Clipped layers stay with their base, and a paste inside a folder is inserted above the complete clipping unit. Paste clears the active selection. Paste and any folder creation are one undo step. Text fields keep normal text shortcuts.

In unreleased 0.4.0, **Ctrl/Cmd+X** in Mask mode copies selected pixels from the active mask paint step. With no step selected, it uses the last paint step. The clipboard write completes before that step is cleared. **Ctrl/Cmd+Shift+C** copies the visible composite in either mode.

Copy supported static image files in Explorer, Finder, or a Linux file manager that offers `text/uri-list`, then paste them directly. Up to 16 local files paste together in one undo step. PNG16 input keeps its native samples and promotes an 8-bit destination to 16 bit. Undo restores the original depth. SVG file paste creates rendered pixels, while Import retains its editable vector source. A project with no layers accepts a pasted image as a root layer. Resident paste limits files to 128 MiB each and 256 MiB of combined decoded data. Native projects use the shared limits for each image format. An invalid file refuses the batch. Files needing a frame, page or icon-variant choice report that requirement. Use Import to choose their content. Image-only clipboards and older Windows bitmap formats are also supported.


Project tabs use a warm rounded highlight for the active project, an orange dot for unsaved changes and blue text/accent for AI activity. Hover a shortened name to read it in full. The close target belongs to its tab and keeps the guarded Save / Don't Save / Cancel review. Use the arrow beside **+** to choose any open project, including those outside the visible strip. Selecting a hidden project brings its tab into view; horizontal scrolling also remains available. Tab labels and close controls have separate keyboard-focus targets. Unreleased PB-111: drag a tab body to reorder with live placement feedback, then release in the strip. The active document stays selected. Escape or dropping outside cancels; dragging near an edge scrolls hidden tabs into reach.

## Compatibility

In unreleased development builds, click **Why read only?** beside the protected-document status to see the specific unsupported features. The preview uses the file's saved appearance while the original Photoshop layers remain in the source file. A flattened editable copy is an explicit choice and must be saved under a new name.

This is a foundation release, not the complete product roadmap. Editable PSD support includes 8-bit and 16-bit RGB raster layers, nested isolated and pass-through groups, opacity, 16 pixel blend modes, raster masks and default grouped raster clipping stacks. A folder's **Pass Through** blend lets its children and adjustments affect the backdrop outside it; Normal isolates them. Folder opacity/masks control the combined change. Enabled folder effects, folder clipping and merging need an isolated blend. Native 16-bit channels remain authoritative during edits, effects, transforms, clipboard operations and PSD/PNG saving. New canvas offers **8 bit / 16 bit**. Unsupported Photoshop features and embedded profiles open as a protected saved-composite preview at the original depth. Supported RGB matrix ICC profiles display through sRGB; **Convert to sRGB copy** makes an explicitly converted editable copy at that same depth and tags its PSD/PNG output. Unsupported profiles show an unmanaged-preview warning and cannot be converted. **Edit 16-bit copy** creates a flattened editable copy that keeps channel precision and requires a new filename; the original stays untouched. PSB and unsupported color modes still report their limits. See [Photoshop fidelity and current limits](photoshop-fidelity.md).

PeerBrush embeds its editable sources in the PSD and saves normal raster/mask data for other editors. Externally changed standard PSD data invalidates embedded definitions instead of resurrecting stale content.

The renderer displays cached previews through the GPU. Incremental brush coverage, regional compositing and partial texture uploads keep gestures small; full previews use bounded parallel CPU workers. Common expensive 8-bit effects and native 16-bit HSL/color balance/adjustment use optional GPU compute, while simple operations stay on CPU when faster. Native 16-bit blur and bloom retain their precision-preserving CPU implementation. Native 16-bit samples are projected only for screen/agent previews; PNG exports retain their depth. Large-document streaming, disk eviction, full ICC color management, broader Photoshop clipping fidelity and text remain follow-up work. Consult `peerbrush_capabilities` for the exact command surface.

## Recovery and shared control

Each dirty project generates its own native-depth recovery PSD and an index in PeerBrush's runtime folder. The AI connection settings panel offers named recovery entries from the current and preceding session. Recovering opens a new unsaved tab with no original save destination. Recovery is a safety copy; save explicitly to keep work permanently.

AI can reserve specific layers or rectangular regions while you edit elsewhere. Blue outlines and layer badges identify AI reservations and recent AI edits. AI opacity and transform previews ease into place, and hierarchy rows animate into their new folder positions. These are presentation transitions; the current shared document and undo history update immediately. Take back control releases reservations. Agents using the old task ID cannot keep editing under that task.


## Maya-style transforms

Use the small **Q / W / E / R** controls at the bottom right for Deselect, Move, Rotate and Scale. The active mode has an Ember underline; recent AI transform activity appears in blue. The same keyboard shortcuts work after clicking controls, and text fields retain normal typing. Transform modes no longer occupy the left painting toolbar.

**Q** clears the area selection, deselects the active tool and cancels unfinished gestures; **W** shows move; **E** shows rotation; **R** shows scale. Select a layer, then drag the colored X/Y handles or the center handle. Move/scale axis handles constrain that axis. Shift snaps rotation to 15° or makes scaling uniform. Escape cancels a drag. **D** selects the eraser.

Unreleased Shift strokes: Brush, Eraser, Smudge, Clone and Heal join successive Shift-clicks with straight document-space strokes. Hold Shift while dragging to lock the first dominant horizontal/vertical axis. Pressing Shift during a drag starts a constrained tail at the current point; releasing it retains that tail and resumes freehand movement. Brush settings, texture, pressure, selection and mask coverage remain active. Actual rendered previews commit once on release. Escape, tool changes or intervening document edits cancel unfinished work. Click continuity resets after document, revision, tool, target or channel changes; Clone/Heal still require a source.

**Unreleased snapping:** hold Shift during W/E/R gestures to move on an 8-document-pixel grid, rotate in 15° steps, or scale uniformly in 10% steps. Release Shift to return to free values during the same drag. The compact toolbar and canvas labels show snapping and current values; the actual artwork previews through the shared engine, and release commits one undo step.

Gizmos preview the actual pixels and apply one undoable edit on release. An active selection transforms its pixels while preserving the remainder of the layer. Its outline rotates, scales and moves with the content; subsequent painting, fills and copying respect that shape. Without a selection, the whole layer transforms. Rotation and scaling resample raster content; undo before trying another transform to retain the original pixels. Whole-group transforms remain planned.

In **Free Transform**, drag just outside the outline to rotate. Use the horizontal and vertical flip icons to reflect the target. The chain icon links the two scale values. The reference grid places the pivot at a corner, edge midpoint, or center of the transformed bounds. For an exact position, drag the pivot on the canvas or enter its X and Y coordinates. Moving the pivot leaves the current preview in place and sets the reference for the next adjustment. **Image Size** uses the same chain icon to keep width and height proportional.

The top bar shows green **MCP connected** when a live client is attached, red otherwise. The animated center line shows agent-supplied progress and tool activity. It is a shared activity display, not access to a model's private reasoning.

## Brush and effects

Unreleased: textured strokes use document coordinates. Grain and Chalk keep their grain fixed to the document pixel grid; Dry combines that grain with brush-oriented fibers, and Bristle follows the brush's dab axes. Moving or expanding raster storage does not shift the texture of an equivalent stroke. Painting, masks, smudge, clone/heal and incremental previews share this behavior at native 8/16-bit depth. Existing painted pixels stay intact.

Unreleased: **Opacity** is directly adjustable beside Size in the top toolbar for Brush, Eraser, Clone and Heal; Smudge shows **Strength**. Drag the compact percentage bar or double-click to enter a value. It uses the same setting as the Brush window and the shared stroke commands. Changing this preference creates no artwork history; painting still commits one undo step per completed stroke. The bar turns blue during AI work with that tool, and human input interrupts the presentation feedback.

Unreleased: Brush, Eraser, Smudge, Clone, Heal and Liquify each remember their own settings across project tabs and app restarts. Switching tools restores size, opacity/strength, flow, hardness, texture, pressure, taper and the applicable preset. Liquify retains its own size, strength and mode. Preset selection copies settings into that tool; subsequent changes leave other tools alone. These preferences save in the instance state directory after a control finishes and do not enter artwork history or PSD files. Invalid or externally changed files remain protected; save failures are shown. AI preference updates commit immediately; compact numeric controls briefly animate in blue, and human input interrupts that feedback.

The Brush window offers 21 original brushes in **Sketch, Ink, Paint, Airbrush, Texture and Blend**. Search or choose a category, then click a readable stroke preview to load all settings. Blend presets select Smudge. Edit any tip, texture, pressure curve, taper, flow or smoothing control, then use **Save new** with a name/category. **Update** and **Delete** apply only to your custom brushes. Custom presets persist in the running instance's state folder independently of artwork and undo. The pressure curve is linear at 1; lower values respond more to light force and higher values need more force.

Unreleased: the new **Basic** section comes first, adding **Hard Round**, **Soft Round**, **Pencil**, **Ink Pen** and **Airbrush** to the existing 21 presets. Use Hard Round for opaque painting, Soft Round for gentle edges, Pencil for fine textured drawing, Ink Pen for smooth lines, and Airbrush for gradual shading. Each preview uses the same brush engine and settings as UI, MCP and CLI strokes; preset selection alone does not edit the artwork.

**[ / ]** (also shifted braces) change brush/eraser size. Hold **S** before starting a stroke and move horizontally to resize, vertically to adjust hardness, with a live tip and numeric readout, without painting. Open Brush settings from the small adjustment icon beside Size: hardness, opacity, flow, spacing, roundness, angle, smoothing, textured tip presets, real pressure when supplied by the platform, and start/end taper. Opacity caps each stroke; flow builds with overlapping dabs. The live stroke uses the same engine as the committed result. Hold **Alt** in Brush for a temporary eyedropper; click to sample, then release Alt to resume painting. The black/white tip remains visible on white artwork.

In 0.4, artwork swatches accept 12-digit RGB and 16-digit RGBA HEX on 16-bit documents. The Eyedropper and temporary Alt eyedropper retain 16-bit color and alpha from the rendered composite. Brush, Eraser, Fill and the canvas shape and gradient tools use the exact values on color layers. New text, editable shapes and pen paths inherit the exact foreground color.

On 16-bit documents the mask swatches offer exact grayscale values from 0 to 65535. Sampling a mask retains its rendered grayscale value at full precision for painting, filling, shapes and gradients.

Each layer and group has a compact connected **Color / Mask** selector. Add levels, curves, Posterize, Gaussian blur, color balance, hue/saturation, bloom, liquify, invert or grayscale to the color stack. Group effects process the combined child content. Posterize's integer Levels control uses 2–256 RGB levels at the document's native depth and preserves alpha; its independent strength sits beside the effect name. The top effect runs last, with earlier effects below it. Blend mode and opacity remain visible beneath the stack. Parameters remain editable after later work; effects can be disabled, reordered or removed. Hover a blend choice for a temporary canvas preview; click to commit it. Double-click a range to type a value, or use the arrow keys to adjust it. Color Balance shows each pair of opposing colors and marks the current value on the ramp.

Add effect stays above the scrollable stack so it remains reachable as the list grows. Its picker has a search field and Tone, Color, Blur & light, Distortion and Mask categories. Search by name or a familiar term such as glow; color and mask stacks show only their supported effects. Tone adjustment belongs in Color effects; the brush toolbar contains brush controls.

Unreleased: the Color effect picker now includes twelve [layer-style effects](layer-styles.md), including Bevel & Emboss, outlines, overlays, inner/exterior glows and shadows. They use the regular editable stack and native-depth rendering. Photoshop style descriptors and embedded patterns remain protected; the new effects have explicit bounded settings and fidelity limits.

**RGBO Clamp** in Color selects Red, Green, Blue or Opacity and clamps that channel between editable Minimum and Maximum percentages. Values already within the bounds and the other channels remain unchanged at full strength. Add separate instances for independent channel limits. Opacity minima also affect transparent pixels within the layer's stored rectangle or the folder's canvas frame. Original pixels remain editable; dragging previews the result and releasing commits one undo step.

**K** selects Magic Wand. Under **Match**, the connected-pixel icon selects matching pixels connected to where you click. The separated-pixel icon selects matching pixels anywhere in the sampled image. Tolerance, merged/active-layer sampling, feathering and Replace/Add/Subtract/Intersect use the same selection system as the Select toolbar. The wand preserves artwork, existing masks and the active Color/Mask channel. **Select → Mask from selection** explicitly converts the selection into a mask when wanted.

Color effects are baked into standard PSD raster data while PeerBrush retains editable effect sources. A group with active color effects is saved as one baked standard layer, with its full editable group and children retained in PeerBrush metadata. Other editors see the current appearance; they cannot edit PeerBrush's effect stack. Blur uses a fast three-pass Gaussian approximation with higher-precision premultiplied working buffers in the 8-bit pipeline; native 16-bit effects have a separate precision-preserving path. Live rendering runs on workers with bounded caches; full tiled GPU compositing and progressive large-document streaming remain planned.


Ctrl/Cmd-click selects multiple layer rows; Shift-click selects a visible range. W/E/R share a pivot and transform the selected raster layers as one gesture. Opacity, blend, new effects and mask controls apply to selected layers together; painting still targets the active layer. Folder-wide transforms remain a later slice. Folders use a folder glyph and heavier name. Drag onto a folder center to move inside, between rows to reorder, or left of nested rows / below the list to move to the top level. The canvas previews the new hierarchy before release.

Press an eye icon and drag vertically across other eyes to show or hide the swept layers together. Release commits one undo step; Escape cancels. Selection boundaries use animated black-and-white marching ants. **Alt+Backspace** floods the active layer or the current selection with the foreground color. **Alt+B** remains available for the selected layers. Mask mode uses the current grayscale foreground; one undo reverses a fill.

Unreleased: **Solo** shows the selected Color or Mask through the shared renderer. The canvas and layer stack name the solo channel and layer, surrounding rows dim while their controls remain usable, and **Exit solo** restores the full document. Selecting another layer or Color/Mask channel exits solo automatically; selecting the same target keeps it. Alt-click a mask thumbnail to toggle that mask's solo view explicitly. Removing the solo layer or mask also restores the full view. Solo is a view setting and creates no document edit or undo step.

MCP starts automatically with the editor. Click **Connect AI** to register with detected Codex, Claude Desktop, Cursor and Gemini CLI clients and publish the local discovery manifest. The neighboring settings control opens advanced/manual configuration. Restart or reload a configured client to load PeerBrush. The adapter can register while the editor is closed and reconnect when you launch PeerBrush. Keep the app open during editing calls. See [MCP and CLI](mcp.md).

## Painting, adjustments and liquify

The brush tip menu shows a sample stroke for **Round**, **Dry**, **Chalk**, **Grain** and **Bristle**. The larger preview shows your current brush settings, including texture density and grain size. **Start / End** taper lengths are measured in document pixels, with separate size and opacity toggles. Mouse strokes can taper without a tablet. Actual pressure is used only when the input platform supplies it. Agent strokes can supply `[x,y,pressure]` points or a parallel `pressures` array.

**U** selects wet blending. **Wetness** controls color mixing, **Pickup** controls pigment collected from the layer, and **Load** adds foreground pigment. Load zero smudges existing artwork. Painting and smudging respect selections and masks.

In 0.4, Smudge Load uses the exact foreground color or mask value on 16-bit documents, including values entered by HEX or sampled with the Eyedropper.

The **◐** layer-header menu adds an adjustment. One selected paint layer gets a clipped adjustment above it; a selected folder gets an adjustment inside it. Multiple selected layers are gathered into a shared color folder. A canvas selection initializes the adjustment mask. Color balance has independent shadow, midtone and highlight controls. Right-click a layer for **Clip to layer below** or **Release clipping**. Keep a base and its clipped layers together when copying, deleting or reordering; incomplete operations are refused before changing the document.

**Bloom** has Threshold, Spread and Strength. **Linear dodge / Add** is available in the blend menu and previews on hover.

Color and mask effects start with settings closed. Select a row to open its settings and management buttons; select it again to close. Every row has an icon and a compact 0–100% strength slider beside its name, independent of its own parameters. Top effects run last. Dragging strength, settings or layer opacity renders the shared engine result while held and creates one undo step on release. Escape cancels the preview. A concurrent document change also cancels it, preserving the newer work. Existing saved effects open at 100% weight. Double-click any slider to type its exact value. Enter or clicking elsewhere accepts a valid value within its range; Escape cancels. Opening or typing in a layer/effect field leaves history unchanged until acceptance, and changing projects or newer document work cancels the pending entry.

**L** selects Liquify. Choose Push, Expand, Pinch or Restore, then brush on the artwork. The rendered warp previews during the drag and commits as one undo step. Its effect remains in the color stack; revisit Amount and individual stroke radius/strength, disable strokes by removal, reorder the effect, or undo. Folder liquify warps its composite. Color liquify is the current scope; this release does not claim Photoshop's full face-aware liquify feature set.

PeerBrush saves supplementary editable effect sources alongside standard PSD pixels. Default grouped raster clipping stacks and raster-only pass-through folders remain separate standard layers with ordinary divider/clipping flags and masks. Unreleased: normal, unclipped, full-weight Invert-only adjustments retain an editable standard Photoshop definition. Other adjustment stacks or clipping involving folders still contain a standard baked composite layer, while PeerBrush restores the full editable tree when the standard data matches. Other editors cannot edit PeerBrush's private effect sources. Externally modified or unsupported sources open protected rather than silently discarding features. See [Photoshop fidelity](photoshop-fidelity.md).


## Selection tools and refinement

Open the selection tool picker to choose a marquee, lasso, or sampled selection. Click the tool name or its icon. The picker announces the current tool to screen readers.

Start a marquee, freehand lasso, Quick Selection, Object region, brush stroke, shape, or gradient drag in the gray workspace around the canvas. Selection drags preview the resulting coverage on the artwork before release, including the selected combination mode and feathering. The document clips coverage at its edges. A primary click in the gray workspace also activates Fill on the current target and selection.

**Unreleased selection updates:** **Ctrl/Cmd+Shift+I** inverts exact selection coverage within the canvas, including feathered edges, through the shared engine. Undo/redo retains the artwork and native depth; text inputs keep their normal shortcuts. With an active pixel selection, **Delete** clears selected pixels from the active layer's Color or selected Mask step, even when other layers are also selected. Feathered edges and holes retain their exact coverage; the layer, selection and unselected pixels remain intact. Without an area selection, Delete removes selected layers. **Ctrl/Cmd+X** copies selected content before one guarded erase. Clipboard failures or intervening edits preserve the source.

Press **M** or click Select in the toolbar. The selection toolbar offers rectangular and elliptical marquees, single rows/columns, freehand and polygonal lassos, Magnetic Lasso, Magic Wand, Quick Selection and Object region. Choose replace, add, subtract or intersect. Hold Shift to add, Alt to subtract, or both to intersect. Feather sets soft edge coverage. Wand, Quick Selection and Object region sample the active layer by default. Under **Sample**, choose the stacked-layer icon to use the visible rendered composite. PeerBrush remembers the choice when you change selection tools. Wand's **Contiguous** option selects matching pixels connected to your click. **All matches** also selects disconnected matches. Quick Selection paints color-connected regions within the brush radius. Magnetic Lasso snaps to nearby rendered luminance edges. Click to begin, follow the edge, and press Enter or double-click to close. Polygonal Lasso uses clicked anchors. Backspace/Delete removes the last anchor. Escape cancels the unfinished path.

In 0.4, **Shift+D** or **Layer → Duplicate with Transform** duplicates selected pixels or selected editable layers and folders. An active pixel selection takes priority over a remembered whole-layer transform when starting a new copy. The selected-pixel copy keeps the original depth and exact coverage, with the source appearance baked into a new paint layer. While that copy stays active, transform tools operate on the whole copy and preserve the original marquee. Free Transform offers **Selected pixels** and **Whole target** to choose the scope. Move, rotate, scale, skew, Distort, use Perspective or apply Grid Warp to whole layers, then press **Shift+D** again to apply the last transform to the next copies. Distort, Perspective and Grid Warp use the same raster target requirements as Free Transform. Grid Warp fits the grid to the placed bounds and repeats the relative control-point positions. Each duplicate and its transform form one undo entry. When the active layer is a duplicated root, its copy becomes active. Changing the active layer, selected layers, channel or tool clears the remembered transform. [Autodesk Maya Duplicate with Transform](https://help.autodesk.com/cloudhelp/2022/ENU/Maya-Basics/files/GUID-8AB8C493-9FC7-437C-82F5-323904ECA9DF.htm)

With **Mask** active and a pixel selection, Shift+D copies the rendered mask into a grayscale paint layer at the same coordinates. Undo returns to the original mask and selected mask step.

When the active layer is inside a selected folder, the copied folder becomes active. If you pick a different layer or channel while duplication finishes, PeerBrush keeps your new target. If the last transform moved only some of the selected layers, Shift+D copies all selected layers and repeats the transform on the corresponding copies. Changing the pixel marquee or editing layer, effect and mask settings keeps the last transform available while the same layers, channel and tool stay active. If an edit clears the remembered transform, an active selected-pixel copy still uses whole-layer scope. Undo and Redo step through those edits, the transforms and the copies in order. They restore the active layer and selection even after a tool change. With the same tool active, Redo also restores a transform applied before the first duplicate, so Shift+D can repeat it. Duplicating after Undo starts a new branch from those layers.

**Select → Deselect** or **Ctrl/Cmd+Shift+D** clears the pixel selection. **Ctrl/Cmd+Alt+D** reselects it. **Ctrl/Cmd+A** selects the canvas.
