# Native task metadata compensation

The Source36 metadata inverse prepares a candidate outside Engine locks. It
does not publish an edit, move a history cursor, authenticate a task, or grant
source authority. The history worker supplies authenticated before, after and
current captures and retains their complete native source owners. Any reported
conflict refuses the entire compensation; generated source outputs require the
existing explicit registered retirement path on refusal.

Portable raster IDs are locations within one capture, not source identities.
The resolver receives a side-qualified physical plane or a reference into its
private prepared table. Equality must perform the required fallible source
validation and compare native data, including padding. The metadata inverse
represents every retained original separately from the current plane and keeps
its matrix, projective transform and warp metadata with that original. The
pixel kernel receives only physical planes. The complete current raster must
equal the task's after-raster before the before-original can be restored;
partial compensation clears the retained original, preserving current pixels.

The final import traversal appends each current plane followed by its retained
original, then mask steps, typed effect coverage, document filters and the two
selection coverages, in the strict Source36 order. Each import returns a
plane-only reference. No reference is compared, reused or adopted by portable
ordinal alone. Ordinary settings objects resembling raster references remain
ordinary metadata because source nodes are installed only at typed locations.

Changed scalar settings are restored only where current still equals after.
Independent later settings survive. ID-based collections preserve later
insertions; task-created sources with later edits, reused removed IDs, missing
edited sources and later parent/clip dependents conflict. Order compensation
changes only common-item slots, preserving later insertion positions, and
refuses a later reorder. Selection rectangle, polygon, coverage and previous
coverage form one atomic state. Each typed clip carries its raster, frame,
origin and contours together. ICC data and its interpretation flag are coupled.
A task changing project identity, frame or channel precision conflicts with any
later document work. Locked layers prevent whole-image filter compensation.
The current revision is retained for the Engine's new compensation record.

All metadata trees are measured and admitted before parsing. A separately
admitted transient workspace covers source tokens, conversion, merged trees,
typed output and bounded diagnostics. Diagnostics refuse beyond 4,096 scopes
or conflicts, 2 MiB of accumulated text, or 4,096 bytes per path. Final candidate
metadata and diagnostics receive fresh measured flat owners; the transient
workspace does not accumulate on successive history entries. The source
resolver separately admits its strong-owner tables and provisional outputs.

This module must be connected to the actual Native history task capture,
reservation checks, source staging, cancellation and final atomic adoption.
Component tests establish the inverse behavior, not complete editor task undo,
release readiness, or a larger document limit.
