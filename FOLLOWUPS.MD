# PeerBrush follow-ups

## Version 0.26 development — unreleased

Responsiveness is priority one after the 2026-10-15 report (PB-108/PB-036/PB-072): painting lags even on a blank canvas, with a constant slight input-to-display delay reported across the application. The first candidate felt about the same: canvas cursor movement, sliders and tool selection still felt delayed. A subsequent candidate removed human-control easing and bypassed vsync; the user reported that cursor and controls felt quicker. Investigate the whole input, preview and presentation path. Initial fixes, the presentation comparison and separate CPU benchmarks are tracked in the [0.26 queue](docs/development-0.26.md#pb-108-application-responsiveness); broader performance and hardware acceptance remain open.

Development continues on `version/0.26`. Bounded integer-grid/layer-aligned gradient shapes and standalone solid Stroke imports retain native sources and require exact standard-composite matching. Supplementary PSD sources now validate standard canvas dimensions. Workspace-cache identity, ownership/save lock lifetime and Unix inode pinning are hardened; Windows keeps its compatible replacement policy. Installed-font presentation preserves shaped filenames/layer names and Ubuntu Sans, with redundant Noto package inputs removed after replacement verification. Current checkpoint evidence and remaining CI, platform, package-size and receiving-application acceptance are tracked in [0.26 development](docs/development-0.26.md). The broader styled original, reported selection recurrence, hardware acceptance and original data-loss incident remain open. Published downloads remain 0.25.
